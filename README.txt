鼓譜練習器 使用說明（最近更新：v7）
====================================
完整更新紀錄請看 CHANGELOG.md。每次功能調整，這份說明與日誌都會一起更新。

【檔案】
index.html ................ 主程式
alphaTab.min.js ........... 修改版 alphaTab（休止符修正，一定要和 index.html 放同一層）
drums.sf2 ................. 譜面鼓聲的音色檔（授權見 LICENSE-GeneralUser-GS.txt）
songs.json ................ 歌曲清單（老師用；學生連結看不到）
songs/ .................... 放 GP 檔（檔名請用英文、數字、減號）
CHANGELOG.md .............. 功能更新日誌

【主畫面】
▶ 播放／暫停、■ 停止、速度（%）與 BPM、🎵 節拍器。其他全部在「⚙ 設定」。

【⚙ 設定】
🔊 發聲：影片／MP3／譜面鼓聲可同時勾選；鼓聲音量、影音音量、鼓組（標準／Room／Power）。
🎵 節拍：4 分或 8 分音符、節拍器音量、預備拍（關／1 小節／2 小節）。
🔁 循環：電腦在譜上拖曳框選；手機按「點選小節範圍」→ 點起點小節 → 點終點小節。
👁 譜面：縮放、每行小節、捲動方式、版面（自動換行／橫向捲動）、聲部。
🛠 老師：起始秒數微調、🎯 抓第一拍（學生連結不會顯示）。

【捲動方式】
預設「倒數第三行就捲動」：游標走到畫面上倒數第三行的行尾，就把該行捲到最上方。
想改成倒數第二行：在 index.html 搜尋 AHEAD_LINES，把 2 改成 1。

【怎麼給學生一個 QR】
1. 把 GP 檔放進 songs 資料夾，改成英文檔名，例如 songs/HandClap.gp，上傳到網站。
2. 用「上線後的網址」打開網站（不是 localhost）。
3. 左邊「快速試用」→「網站上的 GP 路徑」填 songs/HandClap.gp，貼上 YouTube 網址，填起始秒數，按「載入網站上的 GP」。
   （或把歌登記進 songs.json，從左邊清單選歌。）
4. 按「📲 學生連結 / QR Code」→ 下載 QR 圖片，貼進教材。
※ 用電腦裡的檔案載入（「載入測試」）只能自己測試，不能做學生連結。

【更新網站】
到 GitHub 的 drum-lesson：Add file → Upload files，把新的檔案拖進去覆蓋，Commit changes。
網址不變，QR 不會失效。等 1～10 分鐘，手機重新整理；設定面板底部顯示「介面 v7」代表是新版。

【在自己電腦測試】
在資料夾開 PowerShell，輸入：py -m http.server 8000 ，瀏覽器打開 http://localhost:8000
（不能直接雙擊 index.html）

【提醒】
- 放上公開網站的 GP 檔，別人知道網址就能下載；付費譜不要放。
- YouTube 練習影片請關閉營利，否則廣告會讓譜的游標對不上。
- 勾了「影片」時，速度只能用 YouTube 支援的速度（0.25、0.5、0.75、1、1.25 倍…）。
